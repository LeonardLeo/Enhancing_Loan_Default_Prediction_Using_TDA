# Default_Parameters

Tabular machine-learning baselines: library-default classifiers and GridSearchCV on the processed table.

- `1_ML_Default_Parameters` — paper Experiment 1.
- `2_ML_Tuned_Parameters` — paper Experiment 2.
- Does not generate landmarks or barcodes.

## Where to read the method

Open the named dataset script in each dataset folder (for example `Default_Of_Credit_Card_Client_Data/default_of_credit_cards_client_data.py`). That file shows the pipeline in order, with comments at each stage.
