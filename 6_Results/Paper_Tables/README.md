# Paper tables

Aggregation outputs produced by `6_Results/results.py` (run from `6_Results/`).

| File | What it is |
|------|------------|
| `results_table.tex` | Combined paper Experiments 1–10. |
| `statlog_german_credit_results_table.tex` | Statlog slice of the combined table. |
| `default_of_credit_card_client_results_table.tex` | DCCCD slice of the combined table. |
| `results_experiment_1.tex` … `results_experiment_10.tex` | Per-paper-experiment LaTeX tables. |
| `clean_experiment_results.csv` | Flat metric summary kept for the paper/repo. |

Paper experiment numbers in these files are the sequential labels from `results.py`, not the historical folder numbers.
